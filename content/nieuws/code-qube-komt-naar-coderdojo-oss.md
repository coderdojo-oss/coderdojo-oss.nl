Op 16 april komt de Code Qube naar de bijeenkomst van CoderDojo Oss in de Berchplaets!

De Code Qube is een interactief en fysiek hulpmiddel voor kinderen tussen de 10 en 14 jaar om stap voor stap een eigen
website te leren bouwen. Hierbij wordt aandacht besteed aan het design van een website, de HTML en CSS.

Als CoderDojo Oss zijn wij erg blij dat we de Code Qube mogen ontvangen. De verwachting is dat we verschillende kinderen
met de Code Qube kunnen laten werken, maar schrijf op tijd in om teleurstelling te voorkomen.

Mer informatie over de Code Qube is te vinden op <http://www.codeqube.nl/>
